# ⚡ DevTerminal / Code Playground

Un entorno interactivo de terminal y playground web en tiempo real desarrollado con React, Next.js y Tailwind CSS.

## ✨ Features

- **💻 Terminal Interactiva:** Ejecución de comandos, historial y scroll automático.
- **🎨 Code Playground:** Editor vivo para HTML, CSS y JS con vista previa instantánea.
- **⚡ Debounced Render:** Actualización eficiente para no saturar mientras tipeás.
- **📟 Consola Integrada:** Captura de `console.log`, `warn` y `error` desde un iframe aislado.
- **📐 Layout Flexible:** Vista dividida horizontal o vertical.

---

## 🛠️ Comandos Básicos

| Comando | Descripción |
| :--- | :--- |
| `/help` | Muestra la lista de comandos disponibles. |
| `/clear` | Limpia la pantalla de la terminal. |
| `/playground` | Lanza el entorno interactivo de código. |

## 🚀 Inicio Rápido

```bash
# Clonar e instalar
git clone [https://github.com/tu-usuario/dev-terminal.git](https://github.com/tu-usuario/dev-terminal.git)
cd dev-terminal
npm install

# Iniciar servidor
npm run dev
